# Trame Vuetify 4 Demo

This repo is a demo showcasing Vuetify v4's capabilities, as well as to serve
as a testing ground to ensure Vuetify 3 still works.

## Installation

1. Ensure you have uv: `pip install uv`
2. Install the dependencies: `uv sync`

## Running

Any of the examples within `src/` can be ran by the following command:

```bash
python src/vuetify4_features.py --port 8081 --host 10.10.155.14 --server
```
